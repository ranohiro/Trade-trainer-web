# Trade Training Studio

PythonとStreamlitで構築された実践的な株式トレード練習シミュレーターです。
ユーザー認証機能やレベル別の機能制限、レバレッジ規制など、より実戦に近い環境でトレーニングが可能です。

## 概要

このアプリケーションでは、過去の株価データを使用してテクニカルトレードの練習ができます。
現在、以下の機能が実装されています：

### 主な機能
-   **ユーザー認証システム**: レベル別のアクセス権限管理（ユーザーごとの機能制限）。
-   **高度なチャート機能**:
    -   日足（全ユーザー）、週足、指数チャート（Level 2以上）。
    -   移動平均線 (5, 25, 75) およびストキャスティクス (%K, %D, Slow%D)。
    -   5日（ローソク足5本）ごとの背景ストライプ表示。
    -   売買ポイントのチャート上へのマーカー表示。
-   **シミュレーション**:
    -   過去の任意の時点（ランダムまたは最新）からスタート可能。
    -   1日送り、1週間送り機能。
    -   「戻る」機能（Level 3以上）。
-   **トレード管理**:
    -   買い (Buy)、売り (Sell / 空売り)、ドテン売買、決済 (Close)。
    -   **レバレッジ制限**: 有効証拠金の3倍までのポジション制限。
    -   **目標設定**: トレード回数の目標設定と達成時のCSV出力機能。
-   **リアルタイム分析**:
    -   勝率、プロフィットファクター (PF)、含み損益、最大ドローダウンのリアルタイム表示。
    -   資産曲線のグラフ表示。

### 自動バックテストモード (Auto Backtest Mode)
サイドバーの「Application Mode」で「Auto Backtest」を選択することで、以下のロジックに基づいた自動売買検証が可能です。

-   **ロジック**: ストキャスティクスの環境認識 (%D vs Slow%D) とプライスアクション (%K の押し目/戻り) を組み合わせたトレンドフォロー手法。
-   **検証モード**:
    -   **Mode A (Touch)**: 日中の高値/安値タッチでエントリー・損切りを実行。
    -   **Mode B (Close/Next Open)**: 終値ブレイクを確認後、翌日始値でエントリー・損切りを実行。
-   **カスタマイズ**:
    -   シグナル終了（ストキャスティクスのクロス）時の決済タイミング（当日終値 / 翌日始値）を選択可能。
    -   検証期間、初期資金の設定。
-   **結果出力**:
    -   パフォーマンス統計（勝率、PF、総損益など）。
    -   資産推移グラフ（実現損益ベース）。
    -   トレード履歴のCSVダウンロード。

## インストール方法

1.  リポジトリをクローンします。
2.  必要な依存関係をインストールします：

```bash
pip install -r requirements.txt
```

## 使い方

Streamlitアプリケーションを実行します：

```bash
streamlit run app.py
```

### 1. ログイン
起動後、以下のいずれかのユーザーでログインしてください：

| ユーザー名 | パスワード | レベル | 特徴 |
| :--- | :--- | :--- | :--- |
| **user1** | pass1 | 1 | 銘柄固定 (7203.T), 日足のみ |
| **user2** | pass2 | 2 | 銘柄変更可, 週足・指数表示可 |
| **dev** | devpass | 3 | 全機能 + 1手戻る機能 |

### 2. 設定（サイドバー）
-   **Ticker**: トレード対象の銘柄コード（例: 7203.T）。Level 1は変更不可。
-   **Index Ticker**: 参照用の指数（日経平均、TOPIXなど）。
-   **Start Mode**: 開始地点をランダムにするか、最新にするか。
-   **Initial Balance**: 初期資金の設定。
-   **Trade Goal**: 目標トレード回数。

### 3. トレード操作
-   **Next Day (+1)**: チャートを1日進めます。
-   **Next Week (+5)**: チャートを5日（1週間分）進めます。
-   **Order**:
    -   Type: BUY（買い/買戻し）または SELL（売り/空売り）。
    -   Quantity: 株数指定。
    -   **Place Order**: 注文を実行します。証拠金の3倍を超える場合は注文が拒否されます。
-   **Exit**:
    -   **Close Position**: 全ポジションを決済します。

### 4. レビュー
画面下部のタブで情報を切り替えられます：
-   **Daily**: 日足チャート。
-   **Weekly**: 週足チャート（Level 2以上）。
-   **Index**: 指数チャート（Level 2以上）。
-   **Review**: 資産推移グラフとトレード統計詳細。
